# Portfolio Rovane

Portfolio personnel de **Njumssa Tchuimeni Rovane**, réalisé en HTML et CSS.
La page présente une section d'accueil avec le nom, une courte description, une
image de profil et un bouton de contact.

## Structure du projet

```text
portfolio-rovane/
├── index.html   # Structure de la page
├── style.css    # Mise en forme et animations
└── README.md    # Documentation du projet
```

## Lancer le projet

Aucune installation n'est nécessaire. Ouvrez simplement `index.html` dans un
navigateur ou utilisez l'extension **Live Server** de VS Code pour lancer un
aperçu local.

## Personnalisation

- Modifiez le contenu, les liens de navigation et le texte de présentation dans
	`index.html`.
- Ajustez la mise en page, les couleurs et les animations dans `style.css`.
- Remplacez la source de l'image par un chemin relatif au projet, par exemple
	`assets/photo.webp`, afin que l'image fonctionne sur les autres machines.
